# GreenHarvest Project

GoIT HTML+CSS team project scaffold for the GreenHarvest brief.

## Commands

```bash
pnpm install
pnpm run dev
pnpm run build
```

The production output is generated in `dist/`.

## Project Notes

- Built with Vite.
- HTML partials are in `src/partials` and loaded from `index.html`.
- Styles are in `src/css/main.css`.
- SVG sprite is in `src/icons/sprite.svg`.
- Responsive breakpoints target mobile, tablet, and desktop layouts.
